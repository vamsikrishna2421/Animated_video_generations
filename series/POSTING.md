Spacing of ~75 min keeps each Reel from competing with the previous one while it is still
being tested with non-followers. After uploading: **pin the trailer, Episode 1 and Episode 7 (RAG)**
to the top of the profile grid. Episodes end by naming the next one, so viewers binge in order.

**On 10 in one day:** Instagram tests each Reel with a small audience first. Ten back-to-back
split that attention, so each one usually reaches fewer people than it would alone. A common
compromise: launch day = trailer + episodes 1–3, then one episode per day at the same time
(builds a habit and gives the algorithm a daily signal). The captions below work either way.

Common hashtags (add 3–5 of these to every post): `#AIforBeginners #LearnAI #ArtificialIntelligence #AIExplained #TechInTelugu #GenAI #ChatGPT #AIMaastaaru`

## Upload serials (automation)
Every upload has a 3-digit serial in `series/upload_order.json` (serial = position + 1). Files:
`out/<serial>_<id>_<slug>.mp4` and `out/<serial>_<id>_captions.txt` (first line `UPLOAD: <serial>`).
Post strictly in serial order, whatever the id prefix (ep / uc / q). Already-posted uploads live in `out/posted/`.
`out/UPLOAD_ORDER.md` lists every serial with status: posted / ready / rendering soon.
A video only appears in `out/` once it has been rendered from the latest script; stale renders are removed.
Posted so far: 001–023 (trailer + EP 1–22). Next: 024 = EP 23.
