Episode 54 of AI From Scratch: build the simplest AI agent, one tool (Season 6, a screen tutorial)
An agent is an AI that can ask your code to do things. The AI never runs anything itself:
1. Describe the tool, and tell it: to use it, reply with one line of JSON. Here, get_order(order_id).
2. Your code finds that line and runs the lookup. (Twice the AI added a guess after the line, "arrives December 15th"; our code ignored it. The record said Nov 18.)
3. Send the result back. Now it answers from the shop's record: "Your refund process will start once the earphones reach our warehouse."
OpenAI's and Google's own docs describe the same loop (the model returns the tool name and arguments; your app runs it and sends the result back); here it's built by hand.

Our test, a made-up shop with 10 orders, 10 customers, a small free AI on our computer:
- without the tool: 10 answers, no checking; 6 wrong ("refund processed", "shipped", "delivered March 15th"...), 3 right by luck, 1 said "We're checking" (it couldn't check)
- with the tool: 10 lookups, 10 right
If you build one: the AI only asks; your code decides what runs (and who can look up which order). If you use one: check the refund on the shop's own order page. Run a shop? Ask your own bot about an order that doesn't exist: a sure answer is a guess.

The code (Python, every line flat so it survives a comment; ask() = your chat call from EP51):
import json, re
ORDERS = {"4417": {"status": "returned, not yet received at our warehouse", "refund": "not started"}}
def get_order(order_id): return ORDERS.get(order_id, "no such order")
def find_json(reply): m = re.search(r'\{[^{}]*"tool"[^{}]*\}', reply); return json.loads(m[0]) if m else None
TOOL = 'You can use one tool: get_order(order_id) returns the order status and refund. To use it, reply with only: {"tool": "get_order", "order_id": "<the order number>"}. After the tool result, answer only from it.'
messages = [{"role": "system", "content": "You are a shop's support assistant. " + TOOL}, {"role": "user", "content": question}]
reply = ask(messages)
call = find_json(reply)
if call: messages += [{"role": "assistant", "content": reply}, {"role": "user", "content": "Tool result: " + json.dumps(get_order(call["order_id"]))}]; reply = ask(messages)
print(reply)
How we tested (Nov 16, 2026): a made-up online shop (its prompt called it "Kiran Mobiles"; no real shop) with 10 orders we wrote; Qwen2.5-7B-Instruct (4-bit) on llama.cpp on our computer, temperature 0.2, one fresh chat per question, every reply read by hand. Real APIs have a built-in tools option (OpenAI "Function calling", Google "Function calling with the Gemini API"); this is the same loop by hand. In a real shop, check who is asking before get_order answers.
