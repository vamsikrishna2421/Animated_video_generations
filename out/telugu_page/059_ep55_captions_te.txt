AI From Scratch Episode 55: mee sontha MCP server (Season 6, screen tutorial)
MCP (Model Context Protocol) chatbot apps ki oka standard plug: tool ni okkasaari server lo pedithe, MCP telisina prati app adi kanukkoni vaadagaladu. Anthropic open standard ga release chesindi (Nov 2024); ChatGPT company (OpenAI) tana Agents SDK lo cherchindi (Mar 2025).
1. Server: official Python SDK tho 12 lines. Oka function get_order(order_id), oka line description, daani input.
2. Chatbot, server ni "nee daggara e tools unnayi?" ani adugutundi (list_tools); aa javaabu tho tool list tayaru chesukuntundi. Orders gurinchi chatbot lo okka line kooda ledu.
3. Maa test, made-up shop, 10 mandi customers, maa computer lo oka chinna free AI: 10 lo okkate correct. Chatbot order number ni ankega (4388) pampindi; server text adigindi (order_id: str), reject chesindi. Aa okka correct: "4502" ni text ga pampina okkasaari. Maa client code input peru chupinchindi, type chupinchaledu.
4. Fix: ankaina, textaina teesukovaali (order_id: str | int, description lo oka sentence) + chatbot ki types chupinchaali. WhatsApp bot: 1 nunchi 10 ki 10. Website bot: 0 nunchi 7; migilina 3 saarlu tappu format JSON ({"order_id": 4417"}), lookup jaragaledu.
5. Server lo okka maarpu (order 4417: refund approved): chatbot ni maarchakundaane, WhatsApp bot "Your refund of Rs 1,299 has been approved" ani cheppindi.
Meeku edi kaavaali? Okka app ki: maamoolu tool (EP54). Rendu apps daatithe: server.
