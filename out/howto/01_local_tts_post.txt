=== CAPTION ===
Chintu's laptop talked with the Wi-Fi off. Make an AI voice on your own computer: free, offline, no subscription.

ENGLISH: Kokoro (free, Apache 2.0)
1. Python 3.10-3.12. In a terminal:
pip install kokoro soundfile
2. espeak-ng. Linux: sudo apt-get install espeak-ng · Windows: the .msi from github.com/espeak-ng/espeak-ng/releases · Mac: not in the official guides; Homebrew has it: brew install espeak-ng (we haven't tried a Mac)
3. Save these 5 lines as speak.py:
from kokoro import KPipeline
import soundfile as sf
pipeline = KPipeline(lang_code='a')
text = "Hello! This voice was made on a computer, with no internet."
for i, (gs, ps, audio) in enumerate(pipeline(text, voice='af_heart')): print(i, gs, ps); sf.write(f'{i}.wav', audio, 24000)
4. python speak.py → 0.wav. The first run downloads the voice (313 MB); after that, no internet needed.

TELUGU: Indic Parler-TTS by AI4Bharat (free, Apache 2.0): the steps and the code are in the pinned comment.

Our test (a 4-core Intel Xeon at 2.1 GHz, no graphics card):
English: a 4-second line in 1.2 s once loaded (1.2 GB memory)
Telugu: a 5.6-second line in about 30 s (4.7 GB memory)
You need: 8 GB of memory; about 2 GB of disk for Kokoro, 6 GB for Indic Parler (pip also fetches PyTorch the first time).

If it breaks: "espeak-ng not found" → step 2 · Python 3.13 → use 3.12 · the Telugu model says gated or 401 → accept its terms and run hf auth login.
Never share your Hugging Face token.

Save this for later. Next HOW TO (Oct 29): a free AI chatbot on your laptop.

=== PINNED_COMMENT ===
TELUGU VOICE: Indic Parler-TTS (AI4Bharat, Apache 2.0, 21 languages incl. Telugu; Telugu voices: Lalitha, Prakash, Kiran)
1. pip install git+https://github.com/huggingface/parler-tts.git
2. Free Hugging Face account → open huggingface.co/ai4bharat/indic-parler-tts → accept the terms → in a terminal: hf auth login
3. Save as telugu.py:
import torch
from parler_tts import ParlerTTSForConditionalGeneration
from transformers import AutoTokenizer
import soundfile as sf
model = ParlerTTSForConditionalGeneration.from_pretrained("ai4bharat/indic-parler-tts")
tokenizer = AutoTokenizer.from_pretrained("ai4bharat/indic-parler-tts")
description_tokenizer = AutoTokenizer.from_pretrained(model.config.text_encoder._name_or_path)
prompt = "రవి కిరాణా లో దీపావళి ఆఫర్! ప్రతి కొనుగోలు మీద పది శాతం తగ్గింపు."
description = "Lalitha speaks in a clear, friendly voice at a moderate pace. The recording is very clear, with no background noise."
desc = description_tokenizer(description, return_tensors="pt")
prom = tokenizer(prompt, return_tensors="pt")
generation = model.generate(input_ids=desc.input_ids, attention_mask=desc.attention_mask, prompt_input_ids=prom.input_ids, prompt_attention_mask=prom.attention_mask)
sf.write("telugu.wav", generation.cpu().numpy().squeeze(), model.config.sampling_rate)
4. python telugu.py → telugu.wav (the first run downloads 3.75 GB)
