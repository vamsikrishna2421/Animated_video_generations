How we tested (Nov 22, 2026; pipeline/ep58/train_demo.py, committed before it ran): the UCI SMS Spam Collection (5,574 real SMS, 747 spam; UK, about 2012), split 80/20 (seed 58), TF-IDF + logistic regression (scikit-learn) on 4 CPU cores: trained in 1.86 s; on the 1,115 test texts, 135 of 149 scams caught, 1 of 966 genuine texts flagged. Our 3 Indian-style scam texts (made up): lottery caught (0.97), KYC missed (0.25), parcel missed (0.25). The filter (pip install scikit-learn; the data file from the UCI repository):
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.linear_model import LogisticRegression
from sklearn.model_selection import train_test_split
rows = [l.split("\t", 1) for l in open("SMSSpamCollection", encoding="utf-8") if "\t" in l]
y = [1 if lab == "spam" else 0 for lab, _ in rows]; X = [t for _, t in rows]
Xtr, Xte, ytr, yte = train_test_split(X, y, test_size=0.2, random_state=58, stratify=y)
vec = TfidfVectorizer(ngram_range=(1, 2), sublinear_tf=True)
clf = LogisticRegression(max_iter=1000, C=10).fit(vec.fit_transform(Xtr), ytr)
print("right:", (clf.predict(vec.transform(Xte)) == yte).mean())
print(clf.predict_proba(vec.transform(["Your KYC is pending. Update today or your account will be blocked"]))[0][1])
