=== CAPTION ===
Can a free voice assistant understand Telugu? We built one for our made-up phone shop and asked it the same 10 customer questions in English and in Telugu.

Episode 56 of AI From Scratch: build a voice assistant (Season 6, a screen tutorial)
Three pieces, one line of code each:
1. Ears: Whisper (OpenAI's open-source speech model) turns the voice into text, on our own computer.
2. Brain: last episode's bot and order server, unchanged.
3. Mouth: a computer voice reads the answer out.

Our test (computer voices, not real people; scored on whether the right order number reached the shop):
- English, small free model: 7 of 10. 3 numbers came out like prices ("42.90", "46.11").
- Telugu, small free model: 0 of 10. Telugu words written in Hindi letters, or junk.
- When it couldn't read the number, the AI made one up: "12345", 8 times in 50 tries.
- Best free result: a bigger model (Whisper large-v3), translating to English first: 5 of 10, all 5 answers right (in English).
- About 35 s an answer on our computer (4 CPU cores): ears 5, brain 10, mouth 20.
Until it's better: have it read the number back, or let customers type it.

Try it yourself: set your phone's voice typing to your language and say "order forty-four seventeen" (in Telugu, "ఆర్డర్ నలభై నాలుగు పదిహేడు"). See what it types. (Your phone's voice typing is a different system from the free model we tested.)

=== PINNED_COMMENT ===
The voice assistant, runnable (Python 3.10+; pip install faster-whisper mcp==2.3.0 openai; orders_server.py is in EP55's pinned comment). Run: python3 voice_bot.py question.wav
import asyncio, json, re, sys
from faster_whisper import WhisperModel
from openai import OpenAI
from mcp import ClientSession, StdioServerParameters
from mcp.client.stdio import stdio_client
ears = WhisperModel("large-v3", device="cpu", compute_type="int8")  # "small" is faster: 0 of 10 on our Telugu test
llm = OpenAI()  # key in OPENAI_API_KEY (or base_url=... for a local server)
MODEL = "your-model-name"
def hear(wav): return " ".join(s.text.strip() for s in ears.transcribe(wav, task="translate")[0])  # speech -> English text
def ask(msgs): return llm.chat.completions.create(model=MODEL, messages=msgs).choices[0].message.content
def kind(p): return " or ".join(x["type"] for x in p["anyOf"]) if "anyOf" in p else p.get("type", "")
async def main(wav):
    q = hear(wav); print("heard:", q)
    async with stdio_client(StdioServerParameters(command=sys.executable, args=["orders_server.py"])) as (r, w), ClientSession(r, w) as s:
        await s.initialize()
        tools = (await s.list_tools()).tools
        desc = "\n".join(f"- {t.name}({', '.join(f'{k}: {kind(v)}' for k, v in t.input_schema['properties'].items())}): {t.description}" for t in tools)
        msgs = [{"role": "system", "content": "You reply to a shop's customers. Tools:\n" + desc + '\nTo use one, reply with only {"tool": "<name>", "args": {...}}. Then answer only from the result.'}, {"role": "user", "content": q}]
        reply = ask(msgs)
        m = re.search(r"\{.*\}", reply, re.S)
        try: call = json.loads(m[0]) if m else None
        except ValueError: call = None
        if call:
            res = await s.call_tool(call["tool"], call.get("args", {}))
            msgs += [{"role": "assistant", "content": reply}, {"role": "user", "content": "Tool result: " + res.content[0].text}]
            reply = ask(msgs)
        print("answer:", reply)  # the mouth: any text-to-speech reads this out (we used Parler-TTS)
asyncio.run(main(sys.argv[1]))
